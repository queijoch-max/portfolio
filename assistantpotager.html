Mon Assistant Potager

Le projet

Mon Assistant Potager est une application web conçue pour accompagner les jardiniers dans le suivi et l'entretien de leur potager.

L'objectif était de créer un outil simple permettant de centraliser les informations du potager tout en proposant des conseils adaptés en fonction des cultures et des conditions météorologiques.

Ce que j'ai développé

J'ai développé cette application avec React et JavaScript en intégrant une API météo afin d'utiliser des données locales pour enrichir l'expérience utilisateur.

Fonctionnalités principales

  • Gestion d'une liste de cultures présentes dans le potager
  • Suivi d'un calendrier des tâches à réaliser
  • Conseils d'entretien adaptés aux différentes cultures
  • Recommandations personnalisées selon les conditions météorologiques

J'ai également expérimenté l'intégration d'un agent IA afin d'explorer comment l'intelligence artificielle pouvait enrichir les fonctionnalités d'une application web.

Compétences développées

  • Développement front-end avec React
  • Utilisation et intégration d'une API REST
  • Gestion d'une interface utilisateur dynamique
  • Organisation des composants et de la logique applicative
  • Analyse d'un besoin utilisateur et conception d'une solution adaptée
  • Déploiement d'une application web avec GitHub et Vercel
