Delorme Immobilier - Site et back-office avec IA

Site et espace de gestion d'une agence immobilière, avec une IA qui rédige les annonces et répond aux questions des visiteurs.

IA Python Django Ollama / Groq

Le projet

Delorme Immobilier est le site d'une agence immobilière nantaise fictive de 5 agents. L'idée : faire gagner du temps aux agents et mieux renseigner les visiteurs grâce à l'IA, sans jamais perdre le contrôle sur ce qui est publié.

L'agent remplit la fiche d'un bien, l'IA rédige l'annonce, l'agent la relit, la corrige et la publie. Côté visiteur, un chat répond uniquement à partir des fiches publiées.

Ce que j'ai développé

J'ai développé l'ensemble avec Python et Django 5.2 : un site public pensé mobile d'abord, un espace agent protégé, et une couche d'IA indépendante du fournisseur, qui fonctionne aussi bien avec un modèle local (Ollama) qu'avec Groq ou en mode démo.

Fonctionnalités principales

  • Gestion des biens : surface, pièces, quartier, points forts, photos, chaque bien rattaché à un agent
  • Annonces rédigées par l'IA à partir de la fiche, puis relues et corrigées par l'agent avant publication
  • Chat client sur le site public, qui répond uniquement à partir des fiches publiées et refuse les questions hors sujet
  • Tableau de bord agent : « Mes biens » et historique des questions posées au chat
  • Authentification : un compte par agent, chacun ne voit et ne modifie que ses biens, le directeur voit tout

J'ai structuré le code en applications Django séparées (comptes, biens, chat, IA) avec une règle simple : les dépendances ne vont que vers le bas, et le module d'IA ne sait rien de l'immobilier. Le filtre « hors sujet » du chat est évalué avec le vrai modèle grâce à une commande dédiée, et le reste est couvert par 45 tests automatisés utilisant un faux modèle d'IA.

Compétences développées

  • Développement web avec Python et Django
  • Intégration de LLM via une API compatible OpenAI (Ollama, Groq) et architecture à fournisseurs interchangeables
  • Prompt engineering pour la génération de contenu et le cloisonnement d'un chatbot
  • Modélisation de données, droits d'accès par utilisateur et authentification
  • Tests automatisés et évaluation d'un filtre IA avec un vrai modèle
  • Documentation d'architecture et jeux de données de démonstration
