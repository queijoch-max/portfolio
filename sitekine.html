Site vitrine - Cabinet de kinésithérapie

Le projet

Ce site vitrine a été réalisé afin de créer une présence en ligne claire et accessible pour un cabinet de kinésithérapie.

L'objectif était de concevoir un site permettant de présenter le cabinet, les prestations proposées et les informations pratiques, tout en facilitant la prise de rendez-vous pour les patients.

Ce que j'ai développé

J'ai développé ce site en HTML, CSS et JavaScript Vanilla en concevant une interface responsive adaptée aux différents formats d'écran.

Fonctionnalités principales

  • Présentation du cabinet et de son activité
  • Présentation des soins proposés
  • Mise en avant des informations pratiques
  • Prise de rendez-vous via un widget Calendly

J'ai également intégré un widget Calendly afin de permettre aux patients de réserver un rendez-vous directement depuis le site, sans avoir à quitter la page.

Compétences développées

  • Création d'un site vitrine avec HTML, CSS et JavaScript Vanilla
  • Conception d'une interface responsive
  • Structuration et organisation du contenu d'un site web
  • Manipulation du JavaScript côté client
  • Intégration d'un widget externe (Calendly)
  • Déploiement d'un site web avec GitHub et Vercel
