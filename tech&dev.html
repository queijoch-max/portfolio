Tech & Dev - Application web de gestion de projets et tâches

Le projet

Le projet Tech&Dev est un dashboard développeur pensé pour centraliser mon organisation quotidienne. L'objectif était de concevoir un outil complet réunissant la gestion de mes tâches, le suivi de mes projets, mon agenda et mes notes, au sein d'une interface unique — et de l'utiliser réellement au quotidien.

L'objectif était de concevoir un dashboard développeur simple avec gestion de tâches, suivi de projets, agenda et notes et prochainement, un agent intelligent correcteur de code.

Ce que j'ai développé

J'ai développé l'intégralité de l'application, backend compris : une API construite avec Node.js et Express, connectée à une base de données SQLite, et une interface React organisée en plusieurs modules dédiés à chaque fonctionnalité.

Fonctionnalités principales

  • Tableau de bord avec vue d'ensemble (tâches du jour, projets en cours, météo, mini-calendrier)
  • Gestion des tâches avec suivi par période (jour/mois) et édition en direct
  • Suivi de projets avec vue kanban glisser-déposer et tableau détaillé, tri et export des statuts
  • Agenda avec calendrier mensuel, gestion des rendez-vous, et synchronisation automatique des deadlines de projets
  • Espace notes libre et post-it colorés par priorité
  • Authentification sécurisée (mot de passe hashé, jeton de connexion) protégeant l'ensemble de l'application

J'ai également travaillé la structuration du backend (routes, contrôleurs, services), l'organisation des composants React et l'expérience utilisateur, afin de construire une application cohérente et évolutive plutôt qu'un empilement de fonctionnalités isolées.

Compétences développées

  • Développement fullstack avec React, Node.js et Express
  • Conception et modélisation d'une base de données SQLite
  • Construction d'une API REST (routes, contrôleurs, services)
  • Authentification sécurisée (hashage de mot de passe, jetons de connexion, protection des routes)
  • Organisation et réutilisation de composants React
  • Gestion d'état et interactions utilisateur avancées (glisser-déposer, édition en ligne)
  • Intégration d'une API externe (données météo)
  • Versionnement avec Git et GitHub
