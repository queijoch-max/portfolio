Wandora - Réseau social pour voyageur avec carte interactive

Le projet

Le projet Wandora est un réseau social pensé pour les voyageurs qui souhaitent partager leurs itinéraires et leurs souvenirs plutôt que d'entretenir une messagerie permanente comme sur les réseaux classiques.

L'objectif était de concevoir une plateforme centrée sur le partage de voyage : itinéraires, étapes géolocalisées, photos et échanges avec ses ami(e)s, au sein d'une interface unique.

Ce que j'ai développé

J'ai développé cette application avec React et TypeScript pour le frontend, associé à une API backend construite avec Symfony et API Platform, en concevant une interface composée de plusieurs espaces dédiés à la gestion du profil, des voyages et des échanges sociaux.

Fonctionnalités principales

  • Fil d'actualité avec publications multi-photos, réactions et commentaires en fil de discussion
  • Gestion des voyages : création d'itinéraires, étapes géolocalisées sur une carte interactive (Leaflet), et album photo par voyage
  • Système d'ami(e)s avec demandes d'ajout, acceptation/refus et compteur
  • Messagerie interne pour échanger directement depuis le profil d'un(e) ami(e)
  • Authentification sécurisée par token (JWT) et gestion complète du profil utilisateur
  • Interface responsive adaptée aux différents usages

J'ai également travaillé la structuration de l'API (ressources générées à partir des entités backend, sécurisation des accès pour que chaque utilisateur ne voie que ce qui le concerne) ainsi que l'organisation des composants et l'expérience utilisateur côté frontend, afin de construire une application cohérente, sécurisée et agréable à utiliser.

Compétences développées

  • Développement front-end avec React et TypeScript
  • Conception et consommation d'une API REST (Symfony / API Platform)
  • Modélisation de données relationnelles et gestion des accès (authentification JWT, permissions par utilisateur)
  • Organisation et réutilisation de composants
  • Navigation avec React Router
  • Intégration d'une carte interactive (Leaflet)
  • Gestion des interactions utilisateur en temps quasi réel (messagerie, réactions, commentaires)
  • Conception d'une interface responsive
  • Analyse d'un besoin produit et conception d'une architecture backend/frontend découplée
